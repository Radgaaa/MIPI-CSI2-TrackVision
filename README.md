# MIPI-CSI2-TrackVision

This repository is dedicated for my Bachalor's Thesis, it is a work in progress.

## Hardware Setup
- **MCU / Devkit:** phyCORE-i.MX RT1170 (Dual-core: ARM Cortex-M7 + Cortex-M4)
- **Camera Module:** Digilent Pcam 5C (OmniVision OV5640 sensor, MIPI CSI-2)

## Software Dependencies
- **MCUXpresso SDK:** Patched version of NXP SDK for mimxrt1170 from: https://sw.embeddedartists.com/#imxrt1176 (`eaimxrt1176_sdk_2_15_000_2024-02-20.zip`)
